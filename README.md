# DAJKO Garten & Landschaftsbau Website

A modern business website developed for DAJKO Garten & Landschaftsbau, a landscaping and outdoor construction company based in Germany.

Live Website: https://dajkogartenlandschaftsbau.de

## Project Overview

This website was designed and developed to present the company’s landscaping services, completed projects, and contact information through a clean and responsive user interface.

## Features

- Modern responsive design
- Service showcase sections
- Project gallery
- Contact section
- Mobile-friendly layout
- Smooth scrolling interface
- Professional business presentation

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The website was created to improve the company’s online presence and provide potential clients with a professional platform to explore services and completed projects.
